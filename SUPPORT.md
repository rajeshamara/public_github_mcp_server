# Support

This independent RetiMCP public edition is maintained by Rajesh Amara. It is not maintained or supported by GitHub staff.

## Documentation and questions

Start with the [project overview](README.md), [development endpoint guide](retimcp/README.md), and [deployment guide](retimcp/deploy/README.md).

For questions, reproducible bugs, or feature requests about this edition, search and use [this repository's issues](https://github.com/rajeshamara/public_github_mcp_server/issues). Include the source commit, affected component, environment, and a minimal example with synthetic data. Issues and attachments are public: remove tokens, personal information, private source code, and deployment details before posting.

For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of posting details in a public issue.

## Expectations and upstream scope

Help is provided as the maintainer is able to review requests. A response, fix, feature, or review timeline is not guaranteed.

[UPSTREAM_README.md](UPSTREAM_README.md) preserves documentation for the included GitHub MCP Server snapshot. Upstream support and contribution channels concern that separate project. When reporting an upstream issue, first establish that it also occurs in the upstream implementation and follow that project's guidance.
