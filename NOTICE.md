This public edition uses fresh Git history. It preserves the upstream implementation and its README, replaces the top-level introduction with the RetiMCP project overview, and adapts contribution, support, security, and conduct policies for this independent project. Upstream automated workflows, Dependabot configuration, and repository owner routing are omitted. No compatibility claim is made for later upstream revisions.

Installation-specific browser automation, private application regression tools, desktop refresh, and self-deployment integrations are omitted. Public examples use explicit operator configuration and contain no credentials or live infrastructure identifiers.
